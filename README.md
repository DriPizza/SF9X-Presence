# SF9X Presence: Rich Presence for Snes9x Emulator.
Simple rich presence for your Snes9x gameplay!

### Version 1.0:
- No customization;
- 0/200 Games images;
- Changes timer for every game;
- Detects game's name from emulator's window;
- Detects when emulator's inactive or active;

### Disclaimers:
- Made for [Snes9x 1.62.3](https://www.emulator-zone.com/snes/snes9x), thus, use this version;
- Needs [.NET 9.0 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/9.0) to work;
